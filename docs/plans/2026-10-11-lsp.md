# Plan: zor language server

Spec: [../superpowers/specs/2026-10-11-lsp-design.md](../superpowers/specs/2026-10-11-lsp-design.md). TDD throughout. Verify with `cargo test`, `bun test`, `bun run test:grammar`, and `cargo run -- build examples/counter`.

1. **`.zor/` output and checker choice** (`src/build.rs`, `src/bundle.ts`, example tsconfig)
   - `project_root(path)` returns the nearest tsconfig ancestor. `output_path(src)` becomes `<root>/.zor/<rel>.ts`. Unit-test both.
   - The bundle plugin maps `X.tszor` imports into `.zor/`.
   - The default checker is `bun x tsc` when `bun --version` works, otherwise `npx tsc`.
2. **Spans in the AST** (`src/ast.rs`, `src/parser.rs`): add `Src { text, at }`, with equality on text only and `Deref<Target = str>`. Use it for code blocks, imports, expressions, conditions, heads, labels, attribute and element names. Test that `at` points at the text in the source.
3. **Source maps** (`src/codegen.rs`)
   - Make `rewrite` return segments around inserted `this.`.
   - Make `generate` return `Generated { code, mappings }`.
   - Property test over the example files: each mapping copies the source text exactly.
4. **JSON** (`src/json.rs`): parse and serialize. Test round trips, escapes and unicode.
5. **LSP plumbing** (`src/lsp/`)
   - Content-Length framing.
   - UTF-16 position to offset conversion, and URI to path conversion (including percent-decoding `d%3A`).
   - Unit tests for each.
6. **Component features** (`src/lsp/features.rs`): pure functions over a parsed document and an offset, covering completion contexts (component tag, props, `@on` events, `@` keywords), hover text, and definition targets. Unit tests.
7. **Server** (`src/lsp/server.rs`, `zor lsp`)
   - Manage the tsgo child process.
   - Sync documents and write `.zor` files.
   - Route requests (mapped to tsgo, or handled by component features) and map results back.
   - Publish diagnostics.
8. **End-to-end test** (`tests/lsp.test.ts`, Bun): start `zor lsp` against `examples/counter`. Hover `count` in `Counter.tszor` should give `number`. Go to definition on `<Counter` should open `Counter.tszor`. Completion after `<Cou` should offer `Counter`. A type error should appear on the right `.tszor` line.
9. **VS Code client** (`editors/vscode`): `src/extension.ts` with `vscode-languageclient`, bundled by Bun into `out/extension.js`. Server path comes from the `tszor.serverPath` setting, then `<workspace>/target/{release,debug}/zor`, then `zor` on PATH. Package and install.
